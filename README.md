# LoopForge — HTML синтезатор за loop мелодии

LoopForge работи изцяло в браузъра. С него рисуваш мелодии в piano roll и им правиш звука със синтезатор. Добавяш и барабани и експортираш готов WAV loop, който се повтаря без прекъсване във видео монтажа.

## Стартиране

```bash
npm install
```

```bash
npm run dev
```

Отвори http://localhost:5173 в Chrome, Edge или Safari.

Компилираната версия правиш с `npm run build`. Резултатът отива в папка `docs/`, откъдето GitHub Pages сервира сайта. Пътищата са относителни, така че сайтът работи на всеки адрес.

След промяна в кода пусни `npm run build` и качи и папката `docs/` заедно с кода.

## Туториал за начинаещи

При първото отваряне LoopForge предлага интерактивен туториал на български. По-късно го пускаш от бутона **?** горе или от линка в долната лента.

Туториалът те води през 18 стъпки и правиш собствен 4-тактов loop от нулата: барабани → бас → акорди → мелодия → звук → микс → експорт.
- Всяка стъпка свети около копчето, за което говори.
- Задачата се отмята сама, когато я изпълниш.
- Ако заседнеш, има бутони „Покажи ми пример“ и „…вместо мен“.
- Карето се мести с влачене и се свива.
- Прогресът се помни, ако затвориш страницата.

## Какво има

**Синтезатор (за всяка от 4-те мелодични писти)**
- 2 осцилатора (Sine, Triangle, Saw, Square, Pulse с регулируема ширина), sub осцилатор и шум.
- Unison до 7 гласа с detune и stereo width (за „дебел“ звук).
- Филтър LP/HP/BP, 12 или 24 dB, с resonance, drive, envelope amount и key tracking.
- 2 ADSR обвивки (amp и filter) с графика.
- 2 LFO, синхронизирани с темпото. Целта им е pitch, cutoff, volume или pan.
- Poly/Mono режим, glide и чувствителност към velocity.
- Ефекти: Drive, Chorus, Delay (ping-pong, синхронизиран), Reverb и 3-лентов EQ.
- 40 фабрични пресета в 9 категории, плюс твои собствени.

**Piano roll**
- Рисуване, местене, разтягане, изтриване и избор с правоъгълник.
- Тоналност и гама: нотите извън гамата са по-тъмни, а *Scale lock* не позволява фалшиви ноти.
- Акордов инструмент: тризвучие, септакорд, power chord, sus2/sus4 и октава. Акордите винаги са в тоналността.
- Лента за velocity, Quantize, Duplicate, copy/paste.
- Ghost notes показват бледо нотите на другите писти.

**Дължина:** от 1 до 8 такта за кратки loop-ове, или 16/32 такта за цяло парче с интро, куплет, припев и финал.

**Барабани:** 8 синтезирани звука, акценти, готови ритми (Pop/Rock, Lo-fi, Trap, Four on the floor...). Ритъмът е от 1 до 32 такта, така че барабаните могат да се сменят по секции.

**Микс:** volume, pan, mute и solo за всяка писта. Мастерът има glue компресор и limiter.

**Експорт:** WAV 44.1/48 kHz, 16/24-bit, с безшевно повторение и нормализиране.

**Проект:** автоматично се пази в браузъра. Записваш и отваряш файлове `.loopforge.json` и имаш Undo/Redo.

## Пример

`examples/untitled-loop-extended.loopforge.json` е 32-тактов аранжимент (60 BPM, ла минор, около 2:10 мин) с 7 писти. Отваряш го с иконата **папка** горе.

Структура: интро → куплет (оригиналната кука Am → G → G7) → припев с мелодия → брейкдаун → финален припев → аутро.

За да е без повторение, експортирай с **Seamless loop: Off (with tail)**.

## Клавишни комбинации

| Клавиш | Действие |
|---|---|
| `Space` | Play / Stop |
| `A`–`K` (и `W E T Y U`) | Свирене на нотите от клавиатурата |
| `Z` / `X` | Октава надолу / нагоре |
| `1`–`5` | Избор на писта |
| `Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+Z` | Undo / Redo |
| `Ctrl/Cmd+C / V / D / A` | Copy / Paste / Duplicate / Select all |
| `Delete` | Изтрива избраните ноти |
| `↑` `↓` | Транспонира (по гамата). С `Shift` транспонира с октава |
| `←` `→` | Мести избраните ноти по мрежата |
| `Ctrl/Cmd+S` | Записва проекта |

В piano roll-а:
- клик рисува нота, а влаченето задава дължината;
- десен клик или двоен клик изтрива нота;
- `Shift`+влачене избира няколко ноти;
- `Alt`+влачене копира нотите;
- колелцето превърта, а `Ctrl`+колелце увеличава мащаба.

Копчетата се въртят с влачене нагоре/надолу (`Shift` за фино) или с колелцето. Двоен клик връща стойността по подразбиране.

## Как работи безшевният експорт

Loop-ът първо се рендерира няколко пъти „на празно“, докато заглъхнат опашките на reverb и delay. Записва се само следващото повторение. Така опашките от края вече звучат в началото на файла и при повторение няма щракане или тишина.

Фазите на осцилаторите и шумът са фиксирани за всяка нота, затова всяко повторение звучи еднакво.
